Problem 1: My Median

  1. Write an R function called my_median. This function should take a single parameter (a vector) and return the median of that vector. Write this function without using the built-in R command median. Provide the code for this function.

(4 points)

# Example R code
define_my_median <- function(vector) {
  # Code logic here
  n <- length(vector)
  sortedVector <- sort(vector)
  
  if (n %% 2 == 1) {
    return (sortedVector[(n + 1) / 2])
  }
  else {
    return(mean(sortedVector[n / 2], sortedVector[(n / 2) + 1]))
  }
  
}
